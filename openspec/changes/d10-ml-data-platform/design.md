# D10 Design

Python owns D10 validation, governed dataset resolution, deterministic computation, lifecycle, SQLite migration/recovery, and returned evidence. React is a typed renderer and declarative input surface. Rust adds only mutation classification under the established profile ownership lease.

`ml_experiments` remains the pure computation boundary. `desktop_api.ml_lab` owns the D10 profile store and composes governed datasets with that engine. D10 persists experiment evidence, not promoted model authority; D11 consumes immutable D10 identities through public contracts.

The initial catalog is deliberately bounded to three completed-bar return features and two horizon label templates. Arbitrary user code is excluded. A plan pins the selected dataset revision and payload digest; execution re-resolves the governed revision and verifies both identity and integrity before training.
