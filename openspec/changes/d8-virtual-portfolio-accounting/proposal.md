# D8 Proposal — Virtual-Portfolio Accounting Foundation

## Why

D7 can produce governed strategy/backtest evidence, but the desktop product still lacks a durable, auditable simulated-portfolio accounting authority. D8 is the critical-path bridge between historical strategy evidence and D9 forward paper evaluation.

## What changes

- add profile-scoped multiple virtual portfolios;
- add Decimal-safe immutable economic events and append-only balanced journal authority;
- add deterministic cash/position/lot/book-cost/P&L/income/exposure projections;
- add idempotent corporate-action and multi-currency valuation evidence;
- preserve explicit lot allocation rather than inventing a tax disposal policy;
- add non-destructive clone/reset lineage and portable export/restore;
- add a semantic desktop accounting API and Portfolio Lab;
- preserve offline/no-cost workflows and all no-live-execution boundaries;
- repair D7 completion-evidence placeholders and document old milestone-labelled desktop service names as transitional compatibility names.

## Non-goals

Real brokerage sync, tax filing, margin, live execution, recommendations, autonomous real-capital operations, arbitrary user code, and D9 simulated order lifecycle.
