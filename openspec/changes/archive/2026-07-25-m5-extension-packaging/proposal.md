# Proposal - M5 Extension Packaging

## Why

M4 defines extension-compatible research contracts, but OSCA still lacks a governed lifecycle for independently packaged capabilities.

## What Changes

- Add extension manifest contracts.
- Add installation records.
- Add activation decision semantics.
- Add permission-change renewal requirements.
- Add disable/uninstall impact previews.

## Out of Scope

Runtime execution, public registry operation, strategy/backtesting, ML, LLM, paper trading, and live execution.
