# Design

Provider publishes immutable capability, request, observation, result, and failure values through `osca.provider.api`. Adapters implement one application protocol. Provider-specific limitations are data, never alternative contract meaning.

Synthetic stock and crypto adapters are deterministic, credential-free, endpoint-free, and explicitly license-safe. They exercise start-inclusive/end-exclusive ranges, exact decimals, timestamp semantics, policy blocking, unsupported ranges, empty mappings, and typed failures without live network CI.
