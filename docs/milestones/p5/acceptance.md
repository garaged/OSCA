# P5 Acceptance Criteria

| ID | Criteria | Verification |
|---|---|---|
| P5-AC-001 | M0-M12 and P1-P4 docs, specs, ADRs, traceability, manual tests, and source layout are reviewed for drift. | Inspection |
| P5-AC-002 | Known drift in architecture status, README navigation, architecture registry, ADR index, traceability, and manual testing is fixed. | Inspection |
| P5-AC-003 | Provider promotion, no-cost provider catalog, and adapter-contract state are visible through supported operator surfaces. | Automated tests and manual smoke |
| P5-AC-004 | Operator surfaces distinguish implemented, specified-only, fixture-backed, and deferred behavior. | Automated tests |
| P5-AC-005 | Live calls, credentials, runtime routing, production ingestion, and real-capital orders remain disabled or policy-blocked. | Automated tests |
| P5-AC-006 | Requirements, specification, OpenSpec, traceability, manual testing, and hosted Quality evidence are retained. | Traceability audit |
