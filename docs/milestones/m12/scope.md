# M12 Scope

## Included

- Backup package manifests for lightweight, standard, and archival recovery profiles.
- Recovery objectives and isolated restore verification records.
- Disaster-recovery exercise evidence.
- Health findings with impact, remediation, correlation identity, and severity.
- Alert policy metadata with local inbox intent and delivery deferral.
- Durable workflow run records with missed-run approval safeguards.
- Deterministic risk-policy decision records and strict-control fail-closed behavior.
- SQLite metadata persistence for operations evidence.
- Manual smoke coverage for release-readiness operator-visible behavior.

## Excluded

- Real off-device backup transport or cloud storage integration.
- Active restore execution.
- External alert delivery.
- Runtime scheduler execution.
- Personal-server TLS/session implementation beyond accepted M1 skeleton boundaries.
- Live brokerage or exchange execution.
- Real-capital orders.
- Provider production promotion.
