# M10 Intent - LLM Lifecycle and Gateway

M10 establishes the governed language-model lifecycle and gateway foundation required by PRD section 25.

## Intent

Define deterministic, traceable contracts for LLM provider routing, prompt and tool versioning, context selection, privacy classification, resource budgets, structured output expectations, and evaluation evidence.

## Non-goals

- Calling local or remote LLM providers.
- Generating research narratives, recommendations, reports, or tool calls.
- Allowing LLM-initiated live trading or real-capital order placement.
- Enabling automatic state-changing tools.
- Implementing retrieval materialization, vector stores, or prompt execution engines.
