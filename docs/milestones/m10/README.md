Intent -> Requirements -> Architecture -> Specification -> Validation -> Evidence

M10 starts from governed data, research, ML, F2 validation, and F3 paper-evaluation foundations. It introduces LLM lifecycle and gateway contracts for provider-neutral routing, bounded tools, prompt/context versioning, privacy and budget gates, structured output validation, and evaluation evidence before any external provider execution.
