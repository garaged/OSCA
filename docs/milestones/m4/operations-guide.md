# M4 Operations Guide

- **Status:** Draft
- **Last updated:** 2026-07-24

## Purpose

This guide will describe how to create, inspect, validate, and preserve governed exploratory research projects as M4 implementation matures.

## Current behavior

The first M4 slice defines contracts only. There is not yet an end-user workflow or CLI command for project creation, analysis execution, visualization rendering, or report export.

## Current limitations

- External extension packages are not supported until M5.
- Strategy research and backtesting are not supported until M6 and M7.
- Paper trading is not supported until M8.
- ML and LLM workflows are not supported until M9 and M10.
