# M4 Reproducibility Note

- **Status:** Active
- **Last updated:** 2026-07-24

M4 research artifacts must retain enough identity to reproduce or explain an exploratory result:

- project identity and objective;
- hypothesis and timeline events;
- analysis graph identity and node dependencies;
- dataset revision references;
- producer identity and parameter digest;
- analytical output identity and quality state;
- visualization specification and export reproduction metadata.

This note is intentionally limited to M4. Full experiment/model reproducibility arrives in M9, and paper-account reproducibility arrives through M7-M8.
