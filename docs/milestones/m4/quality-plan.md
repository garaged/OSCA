# M4 Quality Plan

- **Status:** Active
- **Last updated:** 2026-07-24

## Quality focus

M4 changes are product- and lineage-sensitive. Validation emphasizes:

- contract schema correctness;
- graph validation failure behavior;
- provenance completeness;
- visualization dependency boundaries;
- documentation and traceability consistency;
- compatibility with M2/M3 market-data semantics.

## Initial test scope

The first slice uses unit tests for contract behavior. Later slices should add application/component coverage for project timelines, ad hoc promotion, graph planning, report assembly, and visualization export workflows.
