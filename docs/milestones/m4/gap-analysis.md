# M4 Initiation Gap Analysis

- **Status:** Initial
- **Baseline:** Completed M3 multi-timeframe temporal correctness
- **Last reviewed:** 2026-07-24

## Baseline strengths

- M1 provides local product skeleton, durable jobs, metadata, security, and validation gates.
- M2 provides governed instruments, provider policies, source/canonical data, retrieval, repair, quality findings, and storage inspection.
- M3 provides interval-aware temporal correctness, OHLCV payloads, resampling lineage, and non-daily publication.

## Gaps addressed by first M4 slice

- No project-level contract for research objective, horizon, and lifecycle state.
- No hypothesis contract with assumptions, expected outcomes, invalidation conditions, confidence, and state.
- No analysis graph contract or graph-shape validation.
- No analytical output taxonomy above governed market data.
- No visualization specification contract that references governed outputs.

## Deferred gaps

- External extension package import and activation remain M5.
- Strategy research, backtesting, and paper trading remain M6-M8.
- ML and LLM lifecycle behavior remain M9-M10.
