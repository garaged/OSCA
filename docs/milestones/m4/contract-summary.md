# M4 Contract Summary

- `osca.research.project` captures project objective, horizon, status, defaults, and dataset revision references.
- `osca.research.hypothesis` captures assumptions, expected outcomes, invalidation conditions, confidence, and state.
- `osca.research.timeline-event` captures typed project history.
- `osca.analysis.graph` captures analysis node dependencies, quality policy, interval requirements, and validation findings.
- `osca.analysis.output` captures typed analytical outputs and provenance.
- `osca.visualization.specification` captures declarative visualization inputs and encoding.
- `osca.visualization.export` captures reproduction metadata for exported visuals.

These contracts are internal and draft extension-compatible for M4. Independent distribution remains M5 scope.
