# D12 Intent — Recommendation Engine and Recommendation Center

## Outcome
Users who explicitly enable the research feature can review ranked, evidence-backed recommendations with confidence, horizon, contradictory evidence, risks, invalidation conditions, uncertainty, provenance, and optional virtual-portfolio impact.

## Scope
Research profile, deterministic eligibility and policy engine, structured recommendation records, ranking, expiry, evidence and contradiction views, historical context, portfolio preview, user disposition, audit, and simulated-action draft creation.

## Non-goals
Personalized financial advice, guaranteed outcomes, automatic execution, AI-authored numerical authority, or default-on recommendations.

## Dependencies
D7 strategy evidence, D9 simulation, and D11 approved models.

## Risks
Advice-like presentation, stale recommendations, hidden contradictions, confidence misuse, suitability ambiguity, and explanation drift from the record.

## Exit intent
The feature requires explicit enablement and boundary acknowledgement; eligibility fails closed; every statement is typed as fact, calculation, model output, heuristic, generated interpretation, or user input; recommendations expire; any action creates only an unconfirmed simulated draft.
