# M9 Scope

## In scope

- Feature and label registry contracts.
- Pluggable training workflow metadata.
- Experiment and model artifact registry contracts.
- Immutable versions and artifact digests.
- Evaluation and calibration reports.
- Deterministic ML promotion decisions.
- F2 event-driven validation integration boundaries.
- Champion/challenger paper-deployment boundaries.
- Drift and outcome monitoring evidence.
- Retraining records without automatic promotion.
- Secure model import/export metadata.

## Out of scope

- Live broker or exchange order execution.
- Automatic promotion from retraining to paper or live use.
- LLM research assistant behavior.
- Production provider promotion.
- Tick/quote/order-book F4 fidelity.
