# M9 Intent - Governed ML Lifecycle

## Intent

Enable ML candidates to be trained, evaluated, compared, promoted into event-driven validation, monitored, and retained with explicit evidence.

## Outcome

M9 establishes the governed ML lifecycle without allowing ML outputs to bypass deterministic validation, paper gates, or user-controlled promotion.

## Boundary

M9 may introduce feature/label registries, training workflow metadata, experiment/model registry contracts, evaluation and calibration reports, drift/outcome monitoring evidence, secure artifact import/export metadata, and champion/challenger paper-deployment decisions.

M9 must not introduce live execution, autonomous real-capital control, unreviewed model promotion, LLM reasoning, or provider production promotion.
