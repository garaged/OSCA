# M8 Scope

## In scope

- Independent paper account contracts
- Approved F2 candidate references
- Forward paper evaluation requests
- Data and operational health gate decisions
- Account pause and system kill-switch controls
- Backtest-versus-forward comparison records
- Later M8 slices for durable schedules, persistence, notifications, recovery, and CLI administration

## Out of scope

- Live execution
- Real brokerage or exchange orders
- Autonomous use of real capital
- Tick-level F4 simulation
- ML and LLM workflows
- Provider production promotion without accepted provider-specific evidence
