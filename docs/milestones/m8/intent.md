# M8 Intent

## Intent

Deliver the F3 paper evaluation and automation foundation so an approved F2 candidate can be represented as a forward paper-evaluation run under deterministic controls.

## Outcome

M8 establishes independent paper account identity, approved-candidate linkage from M7 promotion gates, forward paper run requests, data and operational health gates, account pause/system kill-switch controls, and backtest-versus-forward comparison evidence.

## Starting baseline

M8 starts from merged M7, which provides F2 event-driven validation, balanced journal evidence, valuation/projection records, and promotion gate decisions.

## Non-goals

- Live brokerage or exchange execution
- Real-capital order submission
- Broker/exchange adapter implementation
- ML model lifecycle
- LLM research assistant behavior
- Provider production promotion
- Public notification-provider integration before governed delivery adapters are specified
