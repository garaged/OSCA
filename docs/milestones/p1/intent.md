# P1 Intent

P1 makes provider production promotion governable by defining explicit evidence contracts, deterministic promotion gates, and metadata persistence for paid, authenticated, or license-sensitive provider use.

The milestone targets the already selected Twelve Data and Kraken provider strategy. It requires evidence for licensing, account-plan permissions, named credential references, quota headroom, retention, export, backup, and policy review before a provider can be considered production-enabled.

P1 deliberately avoids live provider retrieval, credential value access, external redistribution, runtime scheduling, live trading, real-capital orders, and provider adapter behavior beyond metadata and deterministic decision records.
