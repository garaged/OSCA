## Required chain

Intent -> Requirements -> Architecture -> Specification -> Validation -> Evidence

P1 starts the post-roadmap sequence by replacing the long-standing provider production promotion deferral with governed evidence gates. It defines promotion evidence and deterministic decisions for Twelve Data and Kraken without adding live provider calls, credential materialization, production ingestion, or external redistribution behavior.
