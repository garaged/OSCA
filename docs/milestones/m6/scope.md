# M6 Scope

## In scope

- Fidelity profile and execution-mode contracts for F0 through F3.
- Point-in-time, revised-after-fact, and provisional data-availability semantics.
- Backtest window, assumption set, request, execution-plan, order-intent, and result contracts.
- Application validation that fails closed on look-ahead data, invalid execution-mode/profile combinations, provisional event-driven data, and deferred forward-paper execution.
- Initial M6 OpenSpec, ADR, requirements allocation, acceptance criteria, tests, and evidence.

## Out of scope

- Event matching and fill simulation.
- Portfolio accounting, journals, and paper accounts.
- Strategy runtime execution.
- Persistent backtest result storage.
- API, web, notebook, and CLI administration for backtests.
- ML, LLM, alerting, and live execution.
