# M5 Deferred Scope

| Deferred item | Target milestone | Reason |
|---|---|---|
| Strategy research and backtesting | M6-M7 | Requires leakage, execution, and evaluation semantics. |
| Paper trading | M8 | Requires paper account, order, fill, risk, and journal contracts. |
| ML lifecycle | M9 | Requires feature, label, training, evaluation, promotion, and drift governance. |
| LLM tools and research assistant | M10 | Requires model gateway, grounding, prompt/tool registry, and evaluation. |
| Public extension registry | Later | Requires publisher identity, distribution, policy, and moderation decisions. |
| Runtime sandbox enforcement | Later M5 slice or follow-up | Requires host/runtime-specific isolation decisions after contract acceptance. |
