# M11 Scope

## Included

- Analysis pack manifest contracts.
- Deterministic pack validation.
- Analytical result bundles with evidence references.
- Cross-family synthesis reports.
- Method comparison reports.
- Outcome calibration reports.
- Portfolio scenario reports.
- Visualization pack metadata.
- SQLite metadata persistence.
- Manual testing and usage updates.

## Excluded

- Runtime analytical engines.
- Provider calls, news retrieval, or on-chain adapters.
- Visualization rendering UI.
- LLM-generated narrative synthesis.
- Recommendation execution, live trading, and real-capital orders.
