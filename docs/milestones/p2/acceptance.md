# P2 Acceptance Criteria

| ID | Requirement | Criterion | Evidence |
|---|---|---|---|
| P2-AC-001 | REQ-0168, REQ-0169 | P2 records a no-cost provider discovery catalog with official-source notes or explicit uncertainty for every candidate. | Inspection |
| P2-AC-002 | REQ-0170, REQ-0171 | Provider entries classify cost model, payment requirement, account/key requirement, and OSCA capability fit. | Inspection |
| P2-AC-003 | REQ-0172 | Licensing or redistribution uncertainty fails closed into conditional, research-only, or excluded disposition. | Inspection |
| P2-AC-004 | REQ-0173 | Rate-limit, quota, fair-access, and user-agent constraints are retained where known. | Inspection |
| P2-AC-005 | REQ-0174 | The catalog identifies a conservative implementation shortlist and sequencing recommendation. | Inspection |
| P2-AC-006 | REQ-0175 | P2 explicitly does not implement adapters, provider calls, credential handling, runtime routing, or production promotion. | Inspection |
| P2-AC-007 | REQ-0176 | Requirements, traceability, ADR, OpenSpec, manual testing, status, and exit evidence are retained. | Hosted Quality and inspection |
