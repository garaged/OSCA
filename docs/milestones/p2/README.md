## Required chain

Intent -> Requirements -> Architecture -> Specification -> Validation -> Evidence

P2 expands the P1 no-cost baseline into a governed discovery catalog for additional no-cost market-data and adjacent-data providers. It classifies candidates and exclusions without implementing adapters, invoking provider APIs, storing credentials, or promoting any provider to production.
