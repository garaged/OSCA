# P2 Scope

## Included

- No-cost provider candidate discovery and classification.
- Official-source evidence notes for selected candidates.
- Candidate suitability for OSCA capability families.
- Licensing, rate-limit, credential, retention, redistribution, and operational uncertainty notes.
- Provider disposition categories: preferred candidate, conditional candidate, research-only, excluded.
- Follow-up implementation sequencing guidance.

## Excluded

- New provider adapters.
- Network calls to providers.
- Credential materialization.
- Production ingestion jobs.
- Runtime provider routing changes.
- Provider promotion decisions.
- Redistribution/export enablement.
- Live execution or real-capital order behavior.
