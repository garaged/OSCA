# U4 - Common Quantitative Analysis

- **Status:** Planned
- **Depends on:** U2-U3

## Objective

Provide a validated built-in library of common descriptive and technical analysis over governed datasets.

## Scope

- Returns, cumulative performance, highs/lows, and gaps.
- SMA/EMA, trend slope, RSI, ROC, MACD, ATR, Bollinger bands, rolling/downside volatility.
- Volume averages/change and OBV where appropriate.
- Drawdown/recovery, Sharpe/Sortino with explicit assumptions, descriptive historical VaR/CVaR.
- Distribution statistics, quantiles, outliers, and autocorrelation.
- Multi-dataset aligned correlation, beta, and rolling correlation.
- Trend/volatility regimes and data-quality findings.
- Parameter, warm-up, source revision, assumption, digest, and finding evidence.

## Non-scope

Advice, target prices, automatic strategy selection, ML training, brokers, or real orders.

## Acceptance

Every formula has independent deterministic fixtures, point-in-time behavior, documented assumptions, chart integration, and exportable evidence.
