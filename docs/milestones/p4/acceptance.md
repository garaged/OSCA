# P4 Acceptance Criteria

| ID | Criteria | Verification |
|---|---|---|
| P4-AC-001 | SEC EDGAR and FRED have deterministic adapter contracts derived from preferred no-cost profiles. | Automated tests |
| P4-AC-002 | SEC EDGAR contracts require public no-key access plus declared user-agent/fair-access constraints. | Automated tests |
| P4-AC-003 | FRED contracts require named API-key references without credential values. | Automated tests |
| P4-AC-004 | Adapter request and fixture validation fail closed for provider or endpoint mismatches. | Automated tests |
| P4-AC-005 | P4 retains the no-live-network, no-routing, and no-promotion boundary. | Inspection |
| P4-AC-006 | Requirements, ADR, OpenSpec, traceability, manual testing, and hosted Quality evidence are retained. | Inspection |
