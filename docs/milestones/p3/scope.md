# P3 Scope

## In Scope

- Provider catalog profile contracts.
- Default profiles for SEC EDGAR, FRED, Alpha Vantage, Nasdaq Data Link, Stooq, and Yahoo Finance unofficial paths.
- Deterministic implementation-readiness classification.
- Tests for preferred, conditional, research-only, and excluded dispositions.
- Governance, specification, OpenSpec, traceability, and manual-testing updates.

## Out of Scope

- Live network calls.
- Provider adapters.
- Credential materialization.
- Runtime provider routing.
- Production promotion decisions.
- External redistribution/export enablement.
