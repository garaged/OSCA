# P3 Risk Register

| ID | Risk | Mitigation |
|---|---|---|
| P3-R-001 | Documentation-only dispositions drift from code behavior. | P3 adds deterministic profiles and tests. |
| P3-R-002 | Excluded providers become adapter candidates by accident. | Readiness classification blocks excluded and research-only providers. |
| P3-R-003 | Conditional providers look ready because they are free-tier. | Conditional dispositions classify as needing evidence. |
| P3-R-004 | Macro/fundamental providers are mistaken for OHLCV substitutes. | Capability classification is explicit. |
| P3-R-005 | P3 is mistaken for production promotion. | Scope and docs keep adapters, calls, credentials, routing, and promotion out of scope. |
