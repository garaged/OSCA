## Required chain

Intent -> Requirements -> Architecture -> Specification -> Validation -> Evidence

P3 turns the P2 no-cost provider discovery catalog into deterministic provider profile contracts and services. It does not implement provider adapters, invoke APIs, materialize credentials, alter runtime routing, or promote providers to production.
