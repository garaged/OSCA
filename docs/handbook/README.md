## Normative boundary

The handbook is explanatory guidance. “Must” obligations originate in the linked requirements, ADRs, policies, and approved specifications. If a handbook summary conflicts with a governing source, the governing source wins and the handbook must be corrected.

## Completion evidence

A contributor can use the reference capability and checklists to classify interactions, identify ownership, recognize public contracts, author a compliant specification, select risk-appropriate evidence, and review a vertical slice without undocumented conventions.
