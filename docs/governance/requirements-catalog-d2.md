# D2 Requirements Catalog Extension

- **Status:** Active D2 catalog extension
- **Governing catalog:** `docs/governance/requirements-catalog.md`
- **Authority:** Accepted desktop product intent, D2 intent, ADR-0046, ADR-0044, and the universal milestone exit gate
- **Purpose:** Allocate stable requirement identifiers for D2 without changing the meaning of the accepted product authority.

This file is an additive part of the requirements catalog. Its identifiers are immutable and must not be reused. The central catalog remains the authority for identifier policy and requirements governance.
