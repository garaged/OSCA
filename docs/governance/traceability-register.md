# Traceability Register

- **Status:** Draft
- **Governing role:** Quality authority
- **Purpose:** Provide the human-reviewable index of relationships among requirements, milestone artifacts, decisions, verification, documentation, and risks.
- **Authoritative sources:** [Requirements catalog](requirements-catalog.md), [traceability model](traceability-model.md)
- **Downstream consumers:** CI validation, milestone reviews, change-impact analysis, and exit evidence

## Register policy

The register summarizes governed links; it does not replace metadata held in the linked artifacts. Automated validation should eventually build or verify this view from repository metadata to reduce manual drift.
