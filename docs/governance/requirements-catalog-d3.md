# D3 Requirements Catalog Extension

- **Status:** Active D3 catalog extension
- **Governing catalog:** `docs/governance/requirements-catalog.md`
- **Authority:** Accepted D3 intent, desktop roadmap, provider admission policy, security-vault architecture, and universal milestone exit gate
- **Purpose:** Allocate stable requirement identifiers for D3.
- **Identifier range:** REQ-0294 through REQ-0308

This file is an additive part of the requirements catalog. Its identifiers are immutable and must not be reused.
