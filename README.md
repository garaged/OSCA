# OSCA

OSCA is a modular market-intelligence and quantitative-research platform for stocks and cryptocurrencies.

The project is currently in product discovery. Its initial product boundary includes multi-source data acquisition, extensible analytics, machine learning and language-model capabilities, reproducible backtesting, and realistic paper trading.
