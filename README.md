# OSCA

OSCA is a modular market-intelligence and quantitative-research platform for stocks and cryptocurrencies.

The product requirements are approved and the project is ready for M0 architecture and engineering-foundation work. Its initial product boundary includes multi-source data acquisition, extensible analytics, machine learning and language-model capabilities, reproducible backtesting, and realistic paper trading.
